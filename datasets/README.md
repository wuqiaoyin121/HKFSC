# Datasets used in the revised HKFSC manuscript

This folder contains exactly the 22 datasets listed in manuscript Table 6: 16 main-comparison datasets and six datasets used in the additional analyses. Each file is a MATLAB v7 `.mat` file with **X** (one sample per row, raw feature values) and **y** (reference class labels). No min–max normalization or dimensionality reduction was applied in these exports. The clustering algorithms must not use `y` during fitting or parameter selection; it is supplied for evaluation.

The four synthetic datasets (`interleaved_moons`, `circle_with_blob`, `swiss_roll`, and `concentric_circles`) were generated by the research project's `data.generate_synthetic` function with MATLAB's `twister` seed **20260915**, matching the experiment configuration. The other 18 files were loaded through the frozen dataset registry and exported without changing sample order. The export checked sample count, feature dimension, and class count against the registry. `manifest.csv` records each file's paper role, source path within the research project, and SHA-256 checksums of both source and export.

The research directory also contains other datasets and explicit hierarchy generators. They are **not** included here because they were not evaluated in the revised manuscript. None of the 22 Table 6 datasets comes with a documented sample-level ground-truth tree or tree-path distance in this release. The synthetic shapes and benchmark class labels should not be presented as proof that the original data have negative curvature.
